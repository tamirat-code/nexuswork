# NexusWork 🚀

### AI-Powered University-Backed Freelance Marketplace

NexusWork is a modern freelance marketplace designed specifically for university students, clients, companies, and universities.

The platform connects **verified university students** with real-world freelance opportunities while giving universities tools to verify students, track skills, and monitor employment outcomes.

It combines **AI-powered project matching, student verification, proposals, contracts, milestones, escrow, wallets, portfolios, reviews, and administrative analytics** into one integrated ecosystem.

---

## 🌟 Vision

NexusWork aims to bridge the gap between **university education and real-world employment** by giving students a trusted platform to gain practical experience, earn income, build professional portfolios, and connect with organizations.

Instead of students graduating with only academic credentials, NexusWork helps them graduate with:

- Real project experience
- Verified skills
- Professional portfolios
- Client reviews
- Freelance income
- Industry connections

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/solomon-dev/nexuswork.git
```

## 2. Enter the project

```bash
cd nexuswork
```

## 3. Install dependencies

```bash
npm install
```

## 4. Start development server

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

# 🔐 Security Architecture

The platform is designed around role-based access control.

```text
                    Authentication
                          │
                          ▼
                    Authenticated User
                          │
             ┌────────────┼────────────┐
             ▼            ▼            ▼
          Student       Client     University
             │            │            │
             └────────────┼────────────┘
                          ▼
                   Role Authorization
                          │
                          ▼
                   Protected Routes
```

Frontend protection is handled through reusable route guards and authentication context.
