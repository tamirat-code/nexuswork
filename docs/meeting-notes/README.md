# Meeting notes

Weekly team meeting notes. This folder holds dated notes, not code
documentation.

## Suggested format

`YYYY-MM-DD.md` per meeting, with:

- **Attendees**
- **Decisions made** — especially ones that change a documented requirement
  or design (if a decision changes something in [`requirements/README.md`](../requirements/README.md)
  or [`architecture/README.md`](../architecture/README.md), update that doc
  too, and link back to the meeting note as the record of *why*).
- **Action items** — who, what, by when.
- **Open questions** carried to the next meeting.

Don't duplicate feature-planning detail that belongs in an issue tracker;
these notes are the record of what was decided and why, not a task board.

For the platform's own video-meeting feature (not this documentation folder),
see [`meetings-and-i18n.md`](../meetings-and-i18n.md).
